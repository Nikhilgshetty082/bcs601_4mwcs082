# BCS601-4MW23CS082

# Project Title

## Student Marks Analyzer Web Application using Python

---

# Introduction

This project is a simple web-based application developed using Python and Flask framework.

The application is designed to calculate:

* Total Marks
* Average
* Percentage
* Grade

The project helps in automating the student marks evaluation process and reduces manual calculation errors. The application is deployed on a cloud platform and can be accessed through a web browser.

---

# Objectives

1. To develop a simple web-based application using Python and Flask framework.
2. To understand and implement basic web development concepts using backend and frontend integration.
3. To calculate student marks including total, average, percentage, and grade.
4. To reduce manual calculation errors and improve accuracy in result processing.
5. To convert the Python program into a web application using Flask.
6. To deploy the application on a cloud platform using Render for online access.

---

# Features

* Student marks calculation using Python
* Automatic calculation of total, average, and percentage
* Grade assignment based on performance
* Simple web interface using Flask
* User-friendly HTML frontend
* Cloud deployment using Render

---

# Technologies Used

* Python
* Flask
* HTML
* GitHub
* Render

---

# Program Description

The application performs the following operations:

* Accepts student name and marks as input
* Calculates total marks obtained
* Calculates average and percentage
* Automatically assigns grade based on percentage
* Displays the final result on a web page using Flask and HTML
