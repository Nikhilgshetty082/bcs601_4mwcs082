# BCS601-4MW23CS082

## Project Title
Student Marks Analyzer Web Application using Python

## Introduction
This project is a simple web-based application developed using Python and Flask.
It calculates total marks, average, percentage, and grade of a student.

The application is deployed on a cloud platform and can be accessed through a web browser.

## Technologies Used
- Python
- Flask
- HTML
- GitHub
- Render

## Features
- Total marks calculation
- Average calculation
- Percentage calculation
- Grade generation
